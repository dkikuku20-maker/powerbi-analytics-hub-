# 💰 Bank Loan Analytics Dashboard

An interactive Power BI dashboard designed to analyze loan performance, borrower trends, lending distribution, and financial risk indicators using banking and loan analytics data.

---

# 📊 Project Overview

This project focuses on transforming financial lending data into actionable business insights to support:

* loan performance monitoring
* borrower analysis
* financial risk evaluation
* lending strategy optimization
* operational banking decisions

The dashboard provides visibility into:

* loan application trends
* funded loan performance
* borrower segmentation
* repayment behavior
* regional loan distribution
* lending risk patterns

---

# 🚀 Dashboard Features

## 📌 Executive Loan Overview

High-level KPI monitoring including:

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average Debt-to-Income Ratio
* Loan Performance Indicators

### Key Insights

* Identified overall lending growth and funding distribution
* Evaluated repayment performance across borrowers
* Monitored key financial health indicators

---

## 📌 Borrower & Loan Analysis

Focused on understanding borrower behavior and lending trends.

### Analysis Includes

* Loan Status Distribution
* Loan Purpose Analysis
* Employment Length Analysis
* Home Ownership Segmentation
* Grade & Risk Distribution
* Borrower Demographics

### Key Insights

* Certain loan purposes generated higher default exposure
* Borrower financial profiles strongly impacted loan outcomes
* Higher-risk loan grades contributed disproportionately to defaults

---

## 📌 Financial Risk & Performance

Focused on operational banking risk analysis and profitability.

### Analysis Includes

* Funded vs Received Loan Comparison
* Interest Rate Trends
* Loan Recovery Performance
* Risk Category Evaluation
* Regional Lending Distribution

### Key Insights

* Loan recovery performance varied across borrower segments
* Interest rate patterns reflected risk-based lending behavior
* Regional loan activity revealed concentration opportunities and exposure
